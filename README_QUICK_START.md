## ⚙️ Próximo Paso (ÚNICO PASO MANUAL)

### Crear las Tablas en Supabase (2 minutos)

1. Abre [tu proyecto Supabase](https://supabase.com)
2. Ve a **SQL Editor** → **New Query**
3. Copia el archivo → `/scripts/001_create_tables.sql`
4. Haz clic en **Run**

✅ ¡Hecho! Las tablas se crearán automáticamente.
